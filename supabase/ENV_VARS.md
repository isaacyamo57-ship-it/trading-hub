# Required Environment Variables for Scanner

Add these to your Vercel project at Settings → Environment Variables:

| Variable | Where to find it | Already set? |
|----------|-----------------|--------------|
| `ANTHROPIC_API_KEY` | Anthropic console | ✅ Already set (used by api/analyse.js) |
| `SUPABASE_URL` | Supabase → Settings → API → Project URL | ❌ Need to add |
| `SUPABASE_ANON_KEY` | Supabase → Settings → API → anon/public key | ❌ Need to add |
